How to use this library

  1. Open the Gemini Gem editor → Knowledge → add files from your device or Google Drive.
  2. Upload PDFs 1–6 first; add 7, 8 and the companion files as space allows.
  3. Paste the Knowledge File Usage Rules at the end of your Gem instructions.
  4. Fill in the Placeholders & Data Request file to replace every [TO BE CONFIRMED].
